# Abel Saferyan — Portfolio

Portfolio personal saya sebagai Web Developer, dibangun dengan React + Vite + Tailwind CSS.

🌐 **Live:** [portofolio-abel-pi.vercel.app](https://portofolio-abel-pi.vercel.app)

---

## Tech Stack

- **React 19** — UI library
- **Vite** — build tool & dev server
- **Tailwind CSS v4** — styling
- **Framer Motion** — animasi
- **Lucide React** — icons

---

## Fitur

- Responsive design (mobile & desktop)
- Smooth scroll navigation
- Animasi interaktif
- Dark theme

---

## Menjalankan Secara Lokal

```bash
# Clone repo
git clone https://github.com/10-Abel-01/Portofolio-Abel.git
cd Portofolio-Abel

# Install dependencies
pnpm install

# Jalankan dev server
pnpm dev
```
